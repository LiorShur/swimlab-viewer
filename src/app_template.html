swimlab · multi-sensor swim analysis

Choose a sensor placement, pick a swimmer, or import a session.
Synthetic pilot data — one synth.generate_swim() body per swimmer, sampled by a virtual sensor at the chosen placement and run through the matching swimlab module (head / sacrum / wrist). Every number is scored against known ground truth in the engine's tests. A static page can't run the Python pipeline, so Import loads an exported session file (export_session.py); raw Movella DOT files need the engine (or a small service) to become one. Validate on real recordings when the hardware lands.
